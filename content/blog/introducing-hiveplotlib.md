Hiveplotlib is a new, open-source Python package for generating hive plots. Originally developed by Martin Krzywinski, hive plots generate well-defined figures that allow for interpretable, visual explorations of network data.

The package lives on [GitLab](https://gitlab.com/geomdata/hiveplotlib), with [documentation](https://hiveplotlib.readthedocs.io/stable/) covering further explanation of hive plots, examples on both toy and real data, and full API documentation.
